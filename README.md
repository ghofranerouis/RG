# 📚 RG Library — Smart University Library (Prototype)

RG Library is an early-stage prototype of a smart university library system.  
The project aims to help students easily discover available books in the university library and receive relevant recommendations through a simple and interactive interface.

At its current stage, the project represents a **conceptual and design prototype**, focusing on presenting the idea and the future vision of the system.

---

## 🎯 Project Idea

University libraries often face challenges such as:
- Difficulty in finding relevant books for a specific topic  
- Lack of guidance for new students  
- Limited interaction between students and library resources  

RG Library aims to:
- Provide a simple and intuitive book search interface  
- Recommend books based on the student’s interests or study field  
- Serve as a foundation for an intelligent decision-support system in the future  

---

## 🧩 Current Project Status

✅ Web-based landing page (UI prototype)
